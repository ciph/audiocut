# 轻剪 AudioCut

Windows 单文件音频播放器与剪辑工具。打开文件自动播放；切换到编辑模式后，可裁剪起止位置、设置淡入淡出，再试听和保存。

## 启动

使用已打包版本时，双击 `dist\AudioCut\AudioCut.exe`，或 `启动轻剪.cmd`。源码仓库不包含 EXE 和 FFmpeg，首次运行源码请按下方“开发与验证”准备环境。也可把一个音频文件拖到窗口或 EXE 上打开。

运行需要 `ffmpeg` 和 `ffprobe` 可从 PATH 访问；迁移到其他电脑时需安装 FFmpeg，或把两个程序放在 AudioCut.exe 同级的 `bin` 目录。移动打包版本时请保留整个 `dist\AudioCut` 文件夹，包括 `_internal`。

## 操作

1. 打开文件后自动播放，点击波形跳转；播放音量只影响监听，不改变导出音量。
2. 点击文件名右侧的剪刀图标切换模式：灰色为播放，蓝色为编辑，再次点击即可切回。切换时波形预览与播放控件保持相同位置和尺寸；模式切换保留编辑结果和播放状态。编辑模式下，左键按住两端范围线的底部方块拖动，调整保留起点或终点。波形中部点击仍用于定位播放。
3. 左键按住顶部三角向内拖动：左端向右拉出淡入，右端向左拉出淡出。三角随曲线端点移动，可反向拖回零；时长最多为整个选区，两段淡化允许重叠。拖动时暂停试听、即时更新曲线，下方简洁状态行显示淡入、淡出秒数（保留三位小数），松开后按空格试听。裁剪缩短选区时，淡化时长也会限制到选区内。
4. 在青色淡化曲线上右键，选择带缩略图的 9 种预设。菜单标记当前选项，右键淡入只修改淡入，右键淡出只修改淡出。时长为 0 时，先用顶部三角拉出曲线，再右键选择形状。
5. 按播放键试听处理后的声音。首次试听需要生成本地临时文件，期间显示进度状态。播放中更换曲线预设会更新预览并从当前片段位置继续播放；暂停时更换保持暂停。切回播放模式保留编辑结果；“重置编辑”恢复原音。
6. 点“保存”设置文件名、格式、目录及 metadata。默认文件名为 `原名_edit`，格式与源一致，目录为源文件所在目录；同名覆盖会询问确认。

保存先在目标目录生成完整的临时输出，再替换目标文件。转码失败不会覆盖原文件。打开新文件或关闭时，尚未保存的修改会有提醒。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+O | 打开音频 |
| 空格 | 播放 / 暂停 |
| Ctrl+E | 切换播放 / 编辑模式 |
| Ctrl+S | 保存 |
| Home | 回到片段开头 |
| 左 / 右方向键 | 波形获得焦点时，移动一秒 |

## 曲线预设

打开文件和重置编辑时，淡入默认选用“正弦（恒功率淡入）”，淡出默认选用“正弦（恒功率淡出）”。菜单按参考图顺序排列：对数（底数 3）、正弦（恒功率淡入）、对数（底数 1.41）、反 S 形曲线、线性、S 形曲线、指数（底数 1.41）、正弦（恒功率淡出）、指数（底数 3）。菜单缩略图按淡入/淡出方向绘制，青色实线与实际处理使用相同的归一化增益。

归一化时间为 x：底数 b 为 3 或 1.41，指数采用 (bˣ−1)/(b−1)，对数采用 ln(1+(b−1)x)/ln(b)，二者互为反函数；S 形与反 S 形分别为半周期余弦和它的反函数；两个正弦预设分别为 sin(πx/2)、1−cos(πx/2)。淡出取 1−f(x)，因此“恒功率淡入”与“恒功率淡出”配对时平方和为 1。两段淡化重叠时，最终增益为各段增益之积。恒功率指配对交叉淡化时的增益平方和，不代表单条音频的功率或主观响度始终不变。

曲线按实际函数自适应细分（屏幕空间阈值 0.12 像素），菜单与波形共用绘制逻辑；曲线和手柄共用端点，采用一致线宽和圆角连接。走带线使用齐平细线和短端帽，绘制范围限制在波形/选区内部。

选项及交互参考 [Wwise 曲线操作说明](https://www.audiokinetic.com/en/public-library/2024.1.5_8803/?id=working_with_curves_in_graph_view&source=Help)。这里采用明确的归一化曲线实现，未与 Wwise 内部插值做逐采样比对；不包含多片段交叉淡化。渲染使用 [FFmpeg aeval](https://ffmpeg.org/ffmpeg-filters.html#aeval) 逐样本计算，并保持输入声道布局。

## 格式与元数据

支持导出 WAV、MP3、FLAC、M4A、AAC、OGG、Opus、AIFF。“与源一致”表示相同文件格式；编辑后会重新编码，有损格式不会逐字节保留源压缩数据。WAV/AIFF 保留合理的源位深，ALAC 来源保存 M4A 时仍使用 ALAC。声道数保持不变；MP3 不接受多于两个声道，部分编码器不支持的采样率会调整到兼容值。

保留 metadata 时，复制目标格式支持的标题、作者、专辑等标签；MP3、FLAC、M4A、AIFF 可保留 JPEG/PNG 封面。章节会按裁剪区间截断并重新计时，再写入支持章节的目标容器。WAV 不保存封面；当前版本 OGG/Opus 只保留文字标签。AAC 使用 ID3v2，标签是否可见取决于播放器。专有标签不保证跨格式保留。取消勾选时去除源标签、章节和封面，但容器仍可能写入必要的格式/编码器信息。

## 开发与验证

需要 Python 3.10+、FFmpeg，以及本目录 `requirements.txt` 的依赖。

```powershell
python -m venv .\.venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

`core.py` 处理检查、波形、滤镜和安全导出；`app.py` 负责后台任务及播放状态；`widgets.py` 提供波形和保存窗；`theme.py` 集中管理样式。测试生成临时音频，不修改用户音频。Qt 播放测试静音，通过实际播放器状态与播放时钟验证；听感仍需在本机扬声器或耳机上确认。

打包：先运行 `.\.venv\Scripts\python.exe -m pip install PyInstaller==6.22.3`，再在本目录运行 `.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --distpath dist AudioCut.spec`。打包前关闭该输出目录中的运行实例。

生成的打包目录、缓存、测试日志、截图和音频文件均不提交到源码仓库。验证方法与已知限制见 [VERIFICATION.md](VERIFICATION.md)。
